# Changelog

## 0.1.1 — 2026-10-10

- Switched live generation to the direct OpenAI Responses API using `OPENAI_API_KEY`.
- Added `gpt-5-mini` as the default; `OPENAI_MODEL` is an optional override.
- Updated setup instructions, configuration detection, and provider routing tests.

## 0.1.0 — 2026-10-09

- Added the Canvas generative UI chatbot in `generative-ui-chatbot/`.
- Added Material UI chat, responsive layout, seven component types, and lazy-loaded MUI X charts.
- Added sales, comparison, request-form and project-progress examples with interactive actions.
- Added optional AI Gateway structured generation and response JSON inspection.
- Added strict request/component validation, timeout, bounded data, and live-call rate limiting.
- Added setup and architecture documentation, API tests and Playwright browser tests.
