# UI with AI

Working experiments in generative user interfaces.

## Canvas: a Material UI chatbot

The first example is in [`generative-ui-chatbot/`](./generative-ui-chatbot). Chat responses contain interactive charts, summary cards, comparisons, forms, progress indicators, and buttons.

```bash
cd generative-ui-chatbot
npm ci
npm run dev
```

Open **http://127.0.0.1:5173**. Demo mode works without API keys. See the [example README](./generative-ui-chatbot/README.md) for live AI setup, architecture, tests, and extension points.
